# Bajwa CPA Premium WordPress Theme

A custom, dependency-free WordPress theme for Bajwa CPA Professional Corporation.

## Install

1. Upload the ZIP from Appearance > Themes > Add New > Upload Theme.
2. Activate Bajwa CPA Premium.
3. Activation automatically creates the homepage, About, Contact, tax checklists, resource pages, service pages, hero slides, navigation and bundled blog articles.
4. Bundled photography is imported into Media Library and assigned as editable Featured Images.
5. If setup was previously skipped, open Appearance > Bajwa Theme Setup and select Create website content.

Setup enables `/%postname%/` permalinks when the site does not already have a permalink structure. It is non-destructive: existing page content, featured images, customized slide fields, selected templates and an edited navigation menu are preserved.

## Edit pages and sections

- Use the normal WordPress block editor for page, service and post content.
- Use Featured Image to replace the designed page-header image.
- Use the Bajwa Page Hero & Design panel to edit the eyebrow, hero heading and introduction.
- Use Additional section HTML for section-by-section HTML or shortcodes. It renders before the global consultation section.
- Edit homepage carousel content under Hero Slides.
- Edit service cards and service-page content under Services.
- Edit blog cards, article content and article imagery under Posts.

## Images

All supplied theme photography is imported into Media Library. Every imported blog article receives an editable Featured Image used consistently on its archive card and article hero. Replacing that Featured Image updates both locations.

## Motion and loading

Section entrances are progressive enhancements and run once. Reduced-motion preferences are respected. The branded Bajwa CPA indicator appears only during real internal navigation and valid contact-form submission; it does not delay or cover the initial homepage hero.

## Performance

PHP and JavaScript syntax are validated locally. Production LCP depends on hosting, caching, plugins, CDN and network conditions. Use full-page caching, Brotli/Gzip, long static-asset cache headers and WebP/AVIF generation for Media Library uploads.
